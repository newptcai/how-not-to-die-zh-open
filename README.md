# 如何不被死神带走

A Chinese-language [Quarto](https://quarto.org) Reveal.js lecture based on
Michael Greger's book *How Not to Die* (《救命》), covering diet, disease
prevention, the environment, and animal welfare.

## Build

```bash
quarto render how-not-to-die.qmd      # → how-not-to-die.html
quarto preview how-not-to-die.qmd     # live preview
```

The deck is 1920×1080 and uses system fonts only; present it in a
Chromium-based browser. Colour emoji come from the presenting machine
(`Twemoji Mozilla` is preferred if installed). Press `s` for speaker notes.
